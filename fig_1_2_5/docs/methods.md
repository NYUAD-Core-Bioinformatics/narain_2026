# Methods

## Mouse habenula atlas figure

The mouse habenula atlas figure was generated from the cleaned whole-habenula AnnData object (`inputs/clean_objects/whole_habenula.h5ad`). The script used the retained raw-count layer for expression summaries and the stored UMAP coordinates and cell-type annotations for visualization. Counts were normalized to 10,000 counts per cell and log1p transformed for marker expression summaries. Broad cell-class marker expression was summarized as dot plots, with point size representing the fraction of cells expressing each marker and color representing scaled mean expression. MHb and LHb subregion panels were generated by scoring predefined marker genes across stored `l04` clusters and assigning each cluster to the highest-scoring regional marker program. Outputs are written to `outputs/figure_1_mouse_habenula_atlas/`.

## Mouse phenotype and regional differential-expression figures

Mouse phenotype differential-expression summaries were generated from curated DE tables in `inputs/figure_2_mouse_differential_expression/`. Major cell-class phenotype DE used the 5000-bootstrap celltype-by-phenotype table, with stress-naive mice as the comparison baseline. LHb and MHb regional phenotype DE used the corresponding region-by-phenotype tables. For each cell type or region and phenotype, unique DE genes were counted and plotted as heatmaps. Outputs are written to `outputs/figure_2_mouse_differential_expression/`.

## Yalcinbas human habenula marker comparison

Human habenula single-nucleus marker genes from Yalcinbas et al. were read from `inputs/figure_5_cross_species/yalcinbas_single_nucleus_marker_genes.csv`. Mouse LHb and MHb regional expression was read from the cleaned lateral and medial habenula objects in `inputs/clean_objects/`. Human marker genes were mapped to mouse genes by gene-symbol matching and the supplied human-mouse gene-symbol table. For each human cluster, the top positive marker genes were displayed across mouse regions as dot plots. Module scores were computed by z-scoring expression across cells and averaging the mapped marker genes for each human cluster. Region-by-cluster marker overlap was tested with one-sided Fisher exact tests using the intersection of eligible mapped human genes and eligible mouse genes as the test universe; P values were adjusted using Benjamini-Hochberg FDR correction. Marker-depth sensitivity analyses repeated Fisher overlap tests across human and mouse marker-depth grids, module scores across human marker-depth grids, and Spearman correlations across mapped marker-effect estimates. Outputs are written to `outputs/figure_5_cross_species/yalcinbas_marker_mapping/` and `outputs/figure_5_cross_species/yalcinbas_sensitivity_analysis/`.

## Yalcinbas bulk schizophrenia overlap

The Yalcinbas bulk schizophrenia-versus-control ranked table was read from `inputs/figure_5_cross_species/yalcinbas_bulk_schizophrenia_ranked_genes.csv`. The top-ranked human genes were compared with mouse major cell-class and regional DE gene sets using one-sided Fisher exact tests over the intersection of eligible human and mouse genes. Directional concordance was summarized from the signs of human and mouse log-fold changes, and P values were adjusted across comparisons by Benjamini-Hochberg FDR correction. Outputs are written to `outputs/figure_5_cross_species/yalcinbas_marker_mapping/` and summarized in `outputs/figure_5_cross_species/yalcinbas_summary/`.

## Kim suicide-associated gene enrichment

Kim et al. suicide-associated habenula genes were read from `inputs/figure_5_cross_species/kim_suicide_habenula_degs.xlsx`. Probe-level gene symbols were cleaned, compound symbols were expanded, and human symbols were mapped to mouse genes using `inputs/figure_5_cross_species/human_mouse_gene_symbols.csv` with case-insensitive matching to genes present in the cleaned mouse objects. For region enrichment, LHb and MHb marker genes were identified from the cleaned lateral and medial habenula objects using Scanpy Wilcoxon rank-sum tests with logFC > 0.25 and adjusted P < 0.05. For cell-type enrichment, major cell-type markers were identified from the cleaned whole-habenula object using one-versus-rest Scanpy Wilcoxon tests with the same thresholds and retaining cell types with at least 50 cells. Kim gene enrichment in each mouse marker set was tested using one-sided Fisher exact tests with the corresponding mouse object gene set as background, followed by Benjamini-Hochberg FDR correction. Outputs are written to `outputs/figure_5_cross_species/kim_region_enrichment/` and `outputs/figure_5_cross_species/kim_celltype_enrichment/`.
